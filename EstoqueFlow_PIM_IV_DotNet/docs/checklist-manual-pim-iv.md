# Checklist do Manual PIM IV

| Etapa do manual | Como o EstoqueFlow atende / situação |
|---|---|
| 1. Caracterização da organização | Mantém a empresa fictícia EstoqueFlow Soluções Operacionais, público-alvo, processos, problemas e oportunidades do PIM III. |
| 2. Planejamento da solução tecnológica | Define problema, objetivo, público-alvo, proposta de valor e benefícios. |
| 3. Responsabilidade social e diversidade | Documentar acessibilidade, VLibras, contraste, navegação por teclado, linguagem simples e inclusão. Não declarar recurso como implementado sem evidência. |
| 4. Desenvolvimento Web com .NET | ASP.NET Core MVC, telas, API REST, validações e estrutura administrativa. |
| 5. Desenvolvimento Mobile | Projeto .NET MAUI inicial consumindo `GET /api/products`. Completar login, telas e sincronização como evolução. |
| 6. Arquitetura de Software | Separação em Models, Data, Services, Controllers e Views; orientação a objetos e modularização. |
| 7. Banco de Dados | SQLite, modelo lógico/físico, MER, script SQL, procedures e triggers. SQLite não oferece stored procedures nativas; documentar essa limitação e usar triggers/consultas parametrizadas, confirmando a exigência com o orientador. |
| 8. Nuvem e DevOps | Apresentar plano de hospedagem, containers, pipeline CI/CD, monitoramento, escalabilidade e segurança. Não afirmar implantação concluída sem evidência. |
| 9. Gerenciamento Ágil | Product Backlog, Sprint Backlog, cronograma, Kanban e entregas. |

## Atenção
O manual exige desenvolvimento de 20 a 30 páginas. A versão final do relatório deve ter o desenvolvimento dentro desse intervalo. Confirmar com o orientador se o protótipo Mobile inicial é suficiente ou se todas as telas e fluxos devem estar implementados.
